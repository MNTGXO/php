# data types
types of data
example:
integer, float , boolean , string ,null ,reasource ,object and array

## integer
it stores whole number
eg:
$a=30;

## float
Decimal numbers. Includes floating-point numbers with varying precision
eg:
$a=7.98;

## string 
Sequence of characters. Can be single-quoted, double-quoted, or defined using heredoc/nowdoc syntax
eg:
$a='musammil';

## boolean
Represents true or false

## null
Represents a variable with no value (null). Used for uninitialized variables or explicitly set to no value.
